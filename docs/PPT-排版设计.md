## Slide 10｜多源行情 ⭐

**页面标题**：多源行情与故障转移

**故障转移链**：
```
Cached API → Yahoo Finance → 新浪财经
   (主源)        (备用)         (A股/港股)
      │            │              │
      └────────────┴──────────────┘
                     │
              ┌──────▼──────┐
              │  内存缓存    │
              │  TTL: 5分钟  │
              └─────────────┘
```

**亮点**：
- ✅ 价格缓存 5min / 历史序列 10min
- ✅ 自动故障转移
- ✅ 优雅降级（返回 — 不崩溃）

## Slide 13｜挑战与反思 ⭐

**页面标题**：挑战与反思

**布局**：问题-修复 对照表

| 问题 | 修复方案 |
|------|----------|
