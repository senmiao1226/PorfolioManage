## ✅ 如何在 PowerPoint 中插入和编辑

### 方法一：直接插入 SVG（推荐 - Office 2019+）

**步骤：**
1. 打开 PowerPoint
2. 点击菜单 **插入** → **图片** → **此设备**
3. 选择对应的 `.svg` 文件
4. 图片将插入到幻灯片中

**编辑方法：**
1. 选中插入的 SVG 图片
2. 右键点击 → 选择 **"转换为形状"** 或 **"取消组合"**
3. PowerPoint 会提示"这是一个导入的对象，是否转换为可编辑的形状？"
4. 点击 **"是"**
5. 现在可以：
   - 修改文字内容和字体
   - 更改颜色和填充
   - 调整形状大小和位置
   - 删除或添加元素

---

### 方法二：使用 Inkscape 编辑后导出（适用于所有版本）

**下载 Inkscape：** https://inkscape.org/ （免费开源）

**步骤：**
1. 用 Inkscape 打开 `.svg` 文件
2. 进行任意编辑（修改文字、颜色、布局等）
3. 导出为 PNG（适合插入 PPT）或直接复制粘贴到 PPT

**优势：**
- 完全控制所有细节
- 可以导出高分辨率 PNG
- 支持批量导出

---

### 方法三：在线编辑工具

**推荐工具：**
- **Figma** (https://figma.com) - 专业设计工具，免费版足够使用
- **Boxy SVG** (https://boxy-svg.com) - 轻量级 SVG 编辑器
- **SVG-Edit** (https://svgedit.netlify.app) - 纯在线编辑器

**步骤：**
1. 访问在线编辑器网站
2. 上传 SVG 文件
3. 编辑后导出为 PNG 或 SVG
4. 插入到 PPT

### 修改文字

所有文字都使用标准字体，可以在 PPT 中直接修改：
- 标题：微软雅黑 / 28px / 加粗
- 副标题：微软雅黑 / 16px / 常规
- 正文：微软雅黑 / 13-15px / 常规

### 调整尺寸

当前画布尺寸：**960 x 540 像素** (16:9 比例)

如果需要调整：
1. 在 PPT 中取消组合后，可以整体缩放
2. 或者在 SVG 文件中修改 `viewBox="0 0 960 540"` 的值

## 💡 最佳实践

### 1. 保持一致性
- 所有图表使用相同的圆角半径（10-15px）
- 边框宽度统一为 2-3px
- 阴影效果保持一致

### 2. 高质量导出
如果导出为 PNG：
- 分辨率设置为 **300 DPI**
- 背景选择透明（如果需要叠加）
- 尺寸至少 **1920x1080**（全屏演示）

### 3. 备份原始文件
- 保留原始 SVG 文件
- 编辑前先另存为新版本
- 方便后续修改

## 🔧 常见问题

### Q1: PPT 中无法取消组合 SVG 怎么办？
**A:** 
- 确认 Office 版本（2019 或 Microsoft 365 支持最好）
- 尝试先插入到 Word，再复制到 PPT
- 使用在线转换工具转为 EMF 格式

### Q2: 文字显示不正常？
**A:**
- 检查是否缺少字体（建议使用微软雅黑或 Arial）
- 在 SVG 编辑器中重新设置字体
- 导出为 PNG 避免字体问题

### Q3: 如何修改图表中的 Emoji 图标？
**A:**
- 在 PPT 中取消组合后，直接删除原 Emoji
- 插入新的图标或表情符号
- 或者在 SVG 文件中修改文本内容

### Q4: 想要添加动画效果？
**A:**
- 取消组合后，每个元素都是独立的形状
- 可以为每个部分单独添加 PPT 动画
- 建议按层级依次出现（标题→内容→箭头）
