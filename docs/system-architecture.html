🚀 后端技术栈

  • Java 17 / Spring Boot 3.x
  • Spring Data JPA / Hibernate
  • MySQL 8.0 数据库
  • SpringDoc OpenAPI (Swagger)
  • RestClient (HTTP 客户端)
  • Lombok (代码简化)

💻 前端技术栈

  • Vue 3 (Composition API)
  • Vite (构建工具)
  • Vue Router (路由管理)
  • Vue I18n (国际化)
  • Axios (HTTP 请求)
  • CSS3 / SVG (图表绘制)

📋 架构设计特点

✅ 分层清晰：严格遵循前后端分离 + 后端五层架构，职责明确
✅ 高可用性：多源故障转移 + 内存缓存，确保服务稳定性
✅ 可扩展性：模块化设计，支持未来添加 Redis、WebSocket 等增强功能
✅ 易维护性：标准化 RESTful API + Swagger 文档，降低协作成本
